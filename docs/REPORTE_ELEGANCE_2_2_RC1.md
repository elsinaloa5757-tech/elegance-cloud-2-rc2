# Elegance Platform 2.2 RC1

Actualización incremental sobre 2.1 RC2 FIX1.

- Biblioteca multimedia persistente con SHA-256, duplicados y estados Activo/Archivado/Papelera.
- Registro automático de fotografías nuevas y registro de archivos existentes.
- Ningún cambio de estado elimina físicamente los originales.
- Casilla individual y acciones masivas: seleccionar, completar, guardar borradores y aprobar/publicar.
- Productos incompletos permanecen en revisión.
- Centro de publicación con catálogo público separado del panel privado.
- El catálogo local funciona en /catalog; el enlace externo requiere despliegue público posterior.
- Se conserva la base de datos y el mecanismo existente crea respaldo previo de versión.
