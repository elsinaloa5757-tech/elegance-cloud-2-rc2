# Elegance Platform

1. Extrae completamente el ZIP.
2. Ejecuta `INSTALAR_ELEGANCE.bat`.
3. Cuando termine correctamente, ejecuta `INICIAR_ELEGANCE.bat`.

La instalación activa se guarda en `%LOCALAPPDATA%\ElegancePlatform`. Los respaldos quedan dentro de su carpeta `backups`.

Consulte `REPORTE_SPRINT_2_RC2.md` para la integración de categorías universales.
