CAMBIOS PRINCIPALES
- Studio usa OpenAI Images Edits con dos referencias: foto original + escenario oficial.
- Reconstruye el contacto mano-producto, iluminación, perspectiva y ambiente como una sola fotografía.
- Auto Sync verifica primero el nombre por consenso web y después genera la imagen final.
- No publica automáticamente sin tres coincidencias web y sin imagen generativa final.
- Se corrigió un error que procesaba cada grupo dos veces.
- Google Vision y OpenAI se configuran desde Configuración.

CLAVES NECESARIAS
1. Google Vision API key: búsqueda visual y consenso de nombres.
2. OpenAI API key: edición generativa real tipo ChatGPT.

Sin OpenAI API key, el sistema usa el compositor local solamente como vista de revisión y no lo considera resultado generativo definitivo.
