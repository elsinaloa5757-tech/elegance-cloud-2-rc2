# Biblioteca Mundial de Moda

La biblioteca está desacoplada del catálogo y del inventario. Su función es describir conocimiento de moda reutilizable: categoría → marca → familia → modelo → variante.

Los datos comerciales (precio, cliente, existencia, imágenes) continúan en el sistema actual. En sprints posteriores podrán vincularse mediante identificadores, sin duplicar conocimiento.
